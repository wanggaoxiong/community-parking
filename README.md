# 邻里停 (Community Parking) · 小区公益智能寻位系统

一套专为地面车位“先到先得”的普通住宅小区打造的**超低成本、零隐私泄露、免施工**开源公益寻位方案。

通过热心业主窗台百元级网络摄像机（定时抓拍 + 移动侦测抓拍上传）与 **本地 OpenCV + Azure AI Foundry 多模态视觉模型** 协同分析，在车主驶入小区大门时以毫秒级语音推荐**离单元门最近、好掉头且不会被前车抢位**的空余车位片区。

---

## 核心特性

1. **隐私安全“四不红线”**
   - **原图零落盘**：内嵌纯内存 FTP / HTTP 接收器，全景抓拍在 RAM 中完成车位裁切后**毫秒级销毁**，磁盘永不保存任何一张原始照片。
   - **前端零实景图**：车主端仅渲染 Apple Maps 风格的抽象红绿车位平面图，杜绝车牌识别与邻里行踪记录。
2. **自适应透视与异形空间标定台**
   - **连排透视自动切分（Homography）**：只需点击一整排车位外框的 **4 个角点 + 输入车位数 $N$**，系统利用单应性透视矩阵自动生成近宽远窄、随灭点倾斜的自适应梯形框。
   - **异形独立车位**：支持任意多边形点选（转角三角位、避让树坑位）及「紧凑小车位（SUV 自动过滤）」标签，采用外接框 + 多边形外掩码涂黑裁切，防止车身拉伸畸变。
   - **无划线弹性顺停带**：针对老小区路侧无固定划线路段，按物理总米数标定，支持连续空档测算与多模态大模型直接判断“还能正常停入几辆普通轿车”。
3. **三级视觉漏斗 + Azure AI Foundry 无缝接入**
   - **Stage 1（0算力）**：32×32 结构帧差拦截 80%+ 静止画面。
   - **Stage 2（<15ms CPU）**：本地 OpenCV 二维梯度能量 + 车窗动态范围对比度 + 锥桶色彩检测。
   - **Stage 3（多模态慢路仲裁）**：原生适配 **Azure AI Foundry**（支持直接粘贴完整 `Target URI`、`*.openai.azure.com`、`*.cognitiveservices.azure.com`、`*.services.ai.azure.com/models`）及 OpenAI / 通义千问 / Gemini / Ollama，精准识别**雪糕桶/电瓶车霸位（`BLOCKED`）**与复杂光影。
4. **双帧防抖状态机 + 180 秒在途软锁**
   - **过滤过路车干扰**：首帧变化进入 `PENDING` 观察态，间隔 $\ge 8\text{s}$ 复核帧一致才翻转状态，避免过路车辆遮挡误报。
   - **在途软锁定**：推荐某片区后自动冻结 1 个在途名额 180 秒，防止同单元前后两辆车被引向同一个孤立车位。

## 快速启动

```bash
# 1. 安装轻量依赖（仅需 OpenCV、NumPy、Pillow、Requests）
pip install -r requirements.txt

# 2. 启动 Web 控制台与内嵌零落盘 FTP 接收服务
python3 run.py --host 127.0.0.1 --port 8790 --ftp-port 2121
```

浏览器打开 `http://127.0.0.1:8790`：
1. 点击右上角 **「配置 Azure 模型」**，粘贴 Azure AI Foundry 部署的 `Target URI`、模型名与 `API Key`，点击「发送测试图验证连通性」。
2. 在 **「空间标定」** 导入基准图，用 4 点透视切分或异形多边形框选车位并保存。
3. 在 **「抓拍测试」** 拖入 AI 生成或实拍的测试图片，实时查看逐车位识别报告与 **「寻位导览」** 语音播报变化。
